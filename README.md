# نظام محاسبة سطح مكتب — متعدد العملاء

برنامج محاسبة بسيط (Python / PySide6 / SQLAlchemy / SQLite) لمحاسب مستقل
يدير حسابات عدة عملاء من جهازه الخاص، بديلاً عن الاتصال عن بعد بأجهزتهم.

- ملف SQLite منفصل لكل عميل (عزل كامل للبيانات)
- قيد مزدوج حقيقي (double-entry) مع فرض التوازن
- الفواتير تولّد قيوداً محاسبية آلياً، المرتجعات تعكس القيد الأصلي
- نظام migration آمن يحافظ على البيانات القديمة عند أي تحديث للـschema

راجع [`WORKFLOW.md`](./WORKFLOW.md) للمعمارية الكاملة وحالة الإنجاز الفعلية.

**تنبيه**: مجلد `data/` (بيانات العملاء الفعلية) مستثنى من git عبر
`.gitignore` — لا يُرفع أي ملف `.db` حقيقي لهذا الـrepo العام تحت أي ظرف.

## التشغيل

```bash
pip install -r requirements.txt
python -m pytest tests/
```
